FIRST-RUN SETUP — FOUR STEPS TO A BUTLER

1 · OWNER PASSWORD

Locks the web UI and API. Chat channels (Slack, Telegram, Teams) authenticate through their own platforms and don't use this.

2 · BRAIN CHECKING…

Simon runs locally via Ollama. Smart model handles complex work; fast model handles quick turns. Add a frontier API key (e.g. Kimi K3) for a cloud top tier — optional but recommended.

3 · CHANNELS OPTIONAL

Skip anything you don't use yet — all of this is editable later in Settings.

4 · MAILBOX OPTIONAL

Microsoft 365 via Graph (application permissions Mail.Read + Mail.Send). Gives Simon his own inbox to read and send from.

Simon restarts himself to apply — back in about 10 seconds.
