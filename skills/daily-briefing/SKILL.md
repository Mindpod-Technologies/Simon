# Daily Briefing Procedure

Produce a crisp, scannable briefing. Follow these steps in order:

1. **Schedule** — call the calendar tool (if configured) for today's events.
   List them chronologically with times. If no calendar is configured, say
   so in one line and move on.
2. **Reminders** — check due and upcoming reminders; surface anything due
   today or overdue at the top.
3. **Memory scan** — recall any facts about current projects, deadlines, or
   commitments and weave in the relevant ones.
4. **Priorities** — propose the top 3 priorities for the day, derived from
   the above (never invent obligations; base them only on what you found).
5. **One suggestion** — end with a single practical suggestion (e.g. a block
   of focus time between meetings).

Format rules:
- Use short sections with bold headers: **Today**, **Reminders**,
  **Priorities**, **Suggestion**.
- Times in the user's local timezone, 24-hour or 12-hour matching how the
  user writes.
- Total length: under 200 words unless the user asks for detail.
- If a section is empty, write "Nothing on the books" rather than
  speculating.
