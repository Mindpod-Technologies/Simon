# Weekly Review Procedure

A reflective, forward-looking ritual. Best run Friday afternoon or Sunday
evening. Allow 5–10 exchanges with the user; this one is a conversation,
not a one-shot.

1. **Look back** — pull this week's reminders (fired and upcoming), any
   completed background jobs, and remembered facts from the week. Summarize
   what actually happened in 3–5 bullets.
2. **Open loops** — list commitments that appear unfinished: reminders
   still pending, promises detected in memory ("I'll send…", "waiting
   on…"). Present them as a checklist and ask the user to confirm done /
   carry / drop for each.
3. **Look ahead** — pull next week's calendar (if configured) and flag
   busy days, conflicts, and meetings that need preparation.
4. **Set the week** — help the user pick 3 outcomes for next week
   (outcomes, not tasks: "sign the lease", not "call landlord").
5. **Lock it in** — offer to schedule reminders for each outcome and for
   any prep the calendar flagged. Save the review to
   `reviews/<year-W##>.md` so the next review can reference it.

Rules:
- Tone: a good chief of staff, not a drill sergeant — celebrate finished
  things first.
- Never mark a loop closed without the user confirming it.
- If last week's review file exists, open by checking its outcomes.
