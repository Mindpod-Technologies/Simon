# Web Research Procedure

Turn a research question into a grounded, cited report.

1. **Frame** — restate the research question in one sentence. If it is
   ambiguous, ask ONE clarifying question before searching.
2. **Search** — run 3–6 web searches with varied phrasings. Prefer primary
   sources (official docs, filings, standards bodies) over aggregators.
3. **Fetch** — fetch the 2–4 most authoritative pages and extract the
   facts that bear on the question. Never cite a page you did not fetch.
4. **Synthesize** — write the report:
   - Lead with the answer/conclusion in 2–3 sentences.
   - Then findings grouped by theme, each claim carrying its source name.
   - A "Conflicts & caveats" section when sources disagree or data is stale.
5. **Save** — write the report to `research/<topic>-<date>.md`
   using the file tools, with a source list (title + URL) at the end.
6. **Reply** — give the user the 2–3 sentence conclusion, the file path,
   and offer to go deeper on any thread.

Rules:
- Distinguish clearly between verified facts (fetched) and inference.
- Note the date of any time-sensitive figures (prices, versions, rankings).
- If searches come back thin, say so plainly rather than padding.
