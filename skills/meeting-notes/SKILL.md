# Meeting Notes Procedure

Convert raw meeting material (transcript, voice-note text, or rough bullets)
into clean minutes.

1. **Identify** — note the meeting's date, participants, and purpose if
   stated. If not stated, mark them as "(unspecified)" — never guess names.
2. **Structure the minutes**:
   - **Summary** — 2–3 sentences on what the meeting was about and its outcome.
   - **Key discussion points** — one bullet per topic, compressed to the
     decision-relevant content.
   - **Decisions** — numbered list of what was actually decided. Separate
     firm decisions from "leaning toward" statements and label the latter.
   - **Action items** — table: owner → task → due date. Use "(unassigned)"
     or "(no date)" when the transcript doesn't say.
3. **Open questions** — list anything raised but not resolved.
4. **Save** — write to `workspace/meetings/<date>-<topic>.md` via the file
   tools.
5. **Reply** — the summary plus the action-item count and file path; offer
   to set reminders for any dated action items.

Rules:
- Compress aggressively; minutes are read, transcripts are not.
- Attribute statements only when the transcript makes attribution clear.
- Flag anything that sounds like a commitment with no owner — that is the
  most common way meetings fail.
